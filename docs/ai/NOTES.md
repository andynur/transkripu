# Decisions & gotchas

One line each, newest at the bottom. Format: `YYYY-MM-DD — topic: note`.

- 2026-09-29 — env: macOS ships Python 3.9 + LibreSSL; yt-dlp dropped 3.9 and HF downloads can fail. Launcher prefers Homebrew Python; tools are installed via brew/pipx.
- 2026-09-29 — network: `Connection reset by peer` from huggingface.co = ISP blocking; fix with another network/VPN once or `HF_ENDPOINT=https://hf-mirror.com`. Model is cached in `~/.cache/huggingface` afterwards.
- 2026-09-29 — yt-dlp: YouTube breaks often ("The page needs to be reloaded"); the fix is `brew upgrade yt-dlp`, needs `deno`. Don't try to patch around it in code.
- 2026-09-29 — perf: don't use `yt-dlp -x --audio-format` (re-encodes, slow). Download `bestaudio[ext=m4a]/bestaudio` with `-N 4`; mlx_whisper reads any container via ffmpeg.
- 2026-09-29 — progress: parsed from mlx_whisper verbose lines `[mm:ss.xxx --> mm:ss.xxx] text` divided by ffprobe duration. Text-mode pipes split tqdm `\r` updates into lines.
- 2026-09-29 — ui: polling (1.2 s busy / 5 s idle) instead of SSE/WebSocket to keep the server trivial. Media element is created once per job so polling doesn't interrupt playback.
- 2026-09-29 — i18n: backend returns `stage`/`error_code` keys; UI translates. Theme via `<html data-theme>`, always light unless the user picked dark (OS preference ignored on purpose); both persisted in localStorage.
- 2026-09-29 — security: `guard_request` blocks foreign `Host` (DNS rebinding) and cross-site `Origin`/`Sec-Fetch-Site` (CSRF: multipart POST needs no CORS preflight). Header-less clients (curl, smoke test) pass.
- 2026-09-29 — cancel: `update()` never revives a CANCELLED job (only retry with `reopen=True`); `run_process` re-checks status after registering the process so a cancel can't slip between. Retry is refused while the worker still holds the job (`current_job`).
- 2026-09-29 — shutdown: tools run with `start_new_session=True`, so Ctrl+C doesn't reach them; `kill_all_procs` runs via atexit (SIGTERM mapped to sys.exit).
- 2026-09-29 — upload: `UploadRequest` spools files into `DATA_DIR/.upload-*.part` so `create_job` renames instead of copying; leftovers removed in teardown and on start.
- 2026-09-29 — perf: progress-only fields are persisted at most 1×/s (`PERSIST_INTERVAL`); drawer polls `?since=N` and appends DOM rows while live; polling stops in hidden tabs.
- 2026-09-29 — tests: `STUB_SLOW` in the prompt makes the mlx_whisper stub sleep 1 s per segment (used by the cancel check).
- 2026-09-29 — launch: `main()` exits if the port is already taken. Before, the browser opened an old server (even one running from a trashed copy), so UI changes seemed not to apply.
- 2026-09-29 — launch: `start.command` reuses a running instance from the same folder (compares the listener's cwd via `lsof`) and refuses if another folder holds the port; `stop.command` kills only processes running `app.py`. `smoke_test.py` re-execs into `.venv` when Flask is missing.
- 2026-09-29 — recap: `claude -p` runs in its own thread (not the GPU worker), cwd = temp dir (else it loads this repo's CLAUDE.md), with `--restricted --tools "" --strict-mcp-config --system-prompt` so user hooks/plugins/MCP don't apply and transcript prompt-injection can't act. Don't use `--bare`: it ignores the OAuth login (API key only). `CLAUDECODE` is removed from the env.
- 2026-09-29 — chat: history lives in SQLite (`data/transkripu.db`, stdlib `sqlite3`, WAL, one connection per call); job state stays in `job.json`. Each question is a stateless `claude -p` call with transcript + recap + last 20 messages on stdin (no `--resume`: nothing hidden in `~/.claude`, the DB is the only history). The answer streams via `stream-json` into `chat_live` and the UI polls `GET /chat` every 0.6 s.
- 2026-09-29 — ai language: recap/chat output language defaults to the recording's language (`default_ai_lang`: chosen spoken language → detected → `en`; Whisper often detects Indonesian as `ms`, mapped to `id`). The drawer EN/ID toggles override it; the chat pick is kept per job (`chat_lang`), the recap's in `recap_lang`. Chat prompt says "answer in X whatever language the question uses" so the toggle wins over the question's language.
- 2026-09-29 — llm: provider layer in `app.py` (`# LLM providers`): OpenAI-compatible HTTP via stdlib `urllib` with SSE streaming, or the `claude`/`codex` CLIs. Settings in `data/config.json` (0600); env keys win; API returns `has_key`/`key_last4` only. Default route Gemini (`gemini-flash-latest`) with `claude_cli` as fallback so a fresh install without a key still works like before. Fallback also triggers on `llm_no_key`/`llm_no_url`/`llm_cli_missing`, not only 429/5xx/timeout.
- 2026-09-29 — llm: kept the existing thread + polling + SQLite design for recap/chat instead of an SSE chat endpoint; `POST /chat/stop` covers the stop button. Gemini answers a bad key with HTTP 400 (mapped to `llm_auth`); Qwen-style `<think>…</think>` is stripped from answers.
- 2026-09-29 — llm: Groq free tier ≈ 8K tokens/min → preset `max_input_tokens: 6000`. Over ~80% of the limit, recaps run map (notes per chunk, paced on 429 `Retry-After` ≤ 60 s) → reduce; chat sends keyword-matched segments ±1 (`meta.excerpt`). Estimate = chars / 3.5.
- 2026-09-29 — codex: verified with `codex-cli 0.155.1`: `codex exec --sandbox read-only --skip-git-repo-check --ephemeral --ignore-user-config --ignore-rules --color never -C <tmp> -o <file> [-m model] -` (prompt on stdin, answer read from `-o`). No system-prompt flag, so the system prompt is prepended.
- 2026-09-30 — ui: model fields use a small custom combobox, not `<datalist>`: browsers filter a datalist by the current value, so a filled field only offered itself. Changing a routing provider clears its model (IDs are provider-specific).
- 2026-09-30 — perf: `whisper_worker.py` keeps mlx_whisper loaded (subprocess on the pipx Python, read from the `mlx_whisper` shim; still invariant 2). Real run: 2.6 s → 0.8 s for the 2nd short job. Cancel kills the worker; it exits after 600 s idle or on stdin EOF, and the server restarts it 30 s before that to avoid a handover race. Start failure → CLI fallback until `/api/health?refresh=1`.
- 2026-09-30 — perf: `GET /api/jobs` ETag = boot id + `jobs_version` (bumped in `update()`/`save()`/delete, also for unsaved progress). JS fetches with `cache: "no-store"` and its own `If-None-Match`, so a 304 reaches the code and skips rendering.
- 2026-09-30 — perf: history rows are patched (key excludes progress + sub-line); chat polls `?after=<last id>` and re-renders only the streaming bubble; drawer asks `?segments=0` once final segments are cached; `.seg` uses `content-visibility: auto`.
- 2026-09-30 — recap: map parts run in a thread pool under sub-keys `recap:<job>#<n>`; `is_stopped()`/`stop_llm()` treat the base key as covering its sub-keys. Presets set `map_parallel: 1` where parallel calls only hit rate limits or one local GPU.
- 2026-09-30 — edit: `PUT /segments/:i` rewrites every `transcript.*` in mlx_whisper's layout (srt/vtt replace `-->` with `->`, txt/tsv/json keep the text; json keeps word timings when the segment count matches). Rerun discards edits.
- 2026-09-30 — ui: a hidden tab polls the list every 5 s (busy) / 30 s so the tab-title progress and notifications keep working; notification permission is asked on the first submit. Player keys are K/Space and J/L; Space is ignored on buttons (focus starts on the drawer's close button).
- 2026-09-30 — tests: the smoke test runs the worker with `TRANSKRIPU_WHISPER_PYTHON=sys.executable` and `PYTHONPATH=scripts/stubs/pylib` (stub `mlx_whisper` package), so the CLI stub only covers the fallback path; check that by hand with `TRANSKRIPU_WHISPER_WORKER=0`.
- 2026-09-30 — deploy: VPS Ubuntu plan (STT replacement for mlx_whisper, YouTube datacenter-IP block, auth/ALLOWED_HOSTS) parked in `docs/ai/VPS_DEPLOY.md`; focus stays local for now.
- 2026-09-30 — captions: URL jobs first run `yt-dlp --skip-download --write-info-json`, pick a track from `subtitles`/`automatic_captions`, then fetch it with `--load-info-json` (no second extraction) as json3 > vtt > srt into `captions.*` (not `source.*`, else `find_downloaded_media` takes it for media). Auto-caption lists include machine translations, so only `<lang>-orig` (or the video's own `language`) is accepted. Any probe/fetch failure (429, PO token) falls back to download + Whisper. `auto` never uses auto-captions; with language `auto` the spoken language is the video's `language`; if the site reports none, manual subs are used only when there is exactly one track.
- Favicons: `static/favicon.svg` is the source; `scripts/make_icons.py` (stdlib only, no Pillow) re-renders `favicon.ico`, `apple-touch-icon.png`, `icon-192/512.png` — keep its geometry in sync when the logo changes. `/favicon.ico` has its own route because browsers request it at the root.
- 2026-09-30 — perf: M1 Pro check (Low Power Mode on battery is the main slowdown, q4 benchmark, open options) in `docs/ai/PERF_M1.md`.
- 2026-09-30 — chat follow-ups: the chat prompt asks for an `@@followups` block after the answer (one LLM call); it is stripped while streaming (`hide_followups`, also a half-received marker) and stored as `meta.suggestions`. Only if the model skips it is `suggest_questions` called separately, still under the `chat:<id>` stop key. Starters for an empty chat come from `POST /chat/suggestions`, cached in `suggestions.json`.
- 2026-09-30 — study tools: chapters and quiz use the *recap* route and answer synchronously (no thread/polling; `study_busy` guards doubles). Replies are JSON parsed leniently (`parse_json_reply` strips ``` fences); invalid chapters (unordered, past the end) are dropped. Quiz answers stay server-side until `/quiz/check`. Tags are saved under `lock` + `save()` directly, since `update()` ignores cancelled jobs. Search scans `segments.json` of done jobs on each request (fine for a local library; add a cache if it gets slow). Transcription estimate = median `duration / timings.transcribe` of earlier Whisper jobs with the same model.
- 2026-09-30 — ui: job detail is a full page at `#/job/<id>` (hash routing, no server route) instead of a right drawer. In-app opens `pushState({fromHome})` so Back uses `history.back()` and restores list scroll/focus; deep links/reloads get a replacing Back. Layout: left = player+chapters+chat, right = transcript whose height matches the left column (`contain: size` + grid stretch, min 480px); recap then quiz span full width below. Transcript scrolls on its own; `scrollSeg()` scrolls only that pane (plain `scrollIntoView` would also scroll the page). `drawer.*` i18n keys kept for the page to avoid churn; only AI settings is still a drawer.
